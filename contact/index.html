Contact

Corrections, bug reports and tool suggestions are all welcome. Specific numbers get the fastest answer.

How to reach us

The site is maintained in public, so the quickest and most reliable channel is the GitHub repository that hosts it:

Open a report on GitHub

You will need a free GitHub account to post there. If you would rather not create one, you can read the repository and the correction history at github.com/Dr-DDon2/Dr-DDon2.github.io.

What to include in a report

  • Which calculator — concrete, seller fees or mouse sensitivity.
  • The exact inputs you entered, with units.
  • The result you got and the result you expected.
  • Where the expected number comes from — a supplier quote, a manufacturer’s bag label, the platform’s fee page, or your own measurement. Screenshots help.

For fee-rate changes, please name the platform, the country of the shop and the rate you were charged. Those numbers vary by market, and a report from one country often explains a “wrong” result reported from another.

Response times

This is a small independent project. Reports are read within a few days, and a confirmed calculation error is usually corrected and republished within a week. Requests for new calculators are collected but not promised — each tool has to be worth building properly, with formulas, examples and tests, rather than a thin page that guesses.

Privacy and data requests

The calculators do not collect anything, so there is no stored profile to request. If you need to reach us about the privacy policy, the same GitHub channel works; please mark the report “privacy”.

What we cannot help with

We cannot quote a price for concrete in your area, order materials, give tax or accounting advice, or tell you which sensitivity is best for your aim. The calculators give you the arithmetic; the decisions and the local prices are yours. For structural work — foundations, retaining walls, anything carrying a building — consult an engineer who can look at the ground.
